# TrialDev verification

TrialDev evaluates whether an analysis system carries a qualified statistical
conclusion into a supported clinical-development decision. The
[report](REPORT.md) presents the evidence across programme structure,
independent reconstruction, controlled response, decision difficulty, and
decision consequences. The [methods](METHODS.md), [numerical results](results/),
and [verification command](REPRODUCE.md) provide the corresponding analysis
definitions and reproducibility path.
